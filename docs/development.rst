Development
===========

mne-denoise welcomes contributions to code, tests, documentation, examples,
and scientific methods.

Development setup
-----------------

.. code-block:: console

   python -m pip install -e . --group dev
   prek install

Common commands
---------------

.. code-block:: console

   spin test
   spin lint
   spin docs
   spin build
   spin check

Contribution guide
------------------

For the complete contribution workflow, scientific contribution requirements,
pull-request guidance, and AI-assisted contribution policy, see
`CONTRIBUTING.md <https://github.com/mne-tools/mne-denoise/blob/main/CONTRIBUTING.md>`__
in the repository.

Changelog entries
-----------------

User-facing changes use Towncrier fragments under ``docs/changes/devel/``.
See `docs/changes/README.md <https://github.com/mne-tools/mne-denoise/blob/main/docs/changes/README.md>`__
for naming and local draft instructions.
