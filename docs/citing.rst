Citing mne-denoise
==================

If you use mne-denoise in scientific work, cite both:

1. the mne-denoise software and the version used; and
2. the primary publication or publications for the scientific method(s) used
   in the analysis.

There is no preferred mne-denoise research paper. The repository contains the
maintainable software citation metadata in :file:`CITATION.cff`; cite the
software release or commit that produced your results. When several methods
are used, cite each method's primary source rather than treating the package
as the source of all of them.

Package extensions and experimental behavior should be described as such. An
extension implemented by mne-denoise should not be attributed to the original
publication, and a public experimental API should not be presented as an
independently validated method.
