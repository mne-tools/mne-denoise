# Documentation versions

## Stable

The stable documentation corresponds to the latest released version of
mne-denoise and is recommended for most users.

[Open stable documentation](https://mne.tools/mne-denoise/stable/)

## Development

The development documentation is built from the current `main` branch and may
include changes that have not been released yet.

[Open development documentation](https://mne.tools/mne-denoise/dev/)

## Previous releases

Previous releases are available from the version selector in the navigation
bar.

For contribution guidance, see the {doc}`Contribute <development>` page.
