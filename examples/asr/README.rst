ASR
===

These examples cover four distinct ASR use cases: transient burst repair
with standard ASR, Riemannian calibration for blink-contaminated EEG,
adaptive calibration when recording statistics change, and Juggler-style
reference selection when clean windows are scarce.

The examples use controlled data when signal preservation requires ground
truth and real EEG when the recording context itself is informative.
Comparisons are illustrative rather than universal benchmarks.
