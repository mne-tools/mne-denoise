SSP-SIR
=======

This example uses a real MNE Sample EEG evoked response as a clean
methodological substrate and adds a controlled short TMS-like muscle artifact.

The artifact direction is constructed with known spatial overlap with a clean
response topography. SSP-SIR is then evaluated with separate artifact
attenuation and clean-input preservation controls using a public MNE forward
solution.

The example is a controlled illustration, not validation on real TMS-EEG.
